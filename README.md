# CNMD 龙悦 PRO

> 小巧不简陋，便携不将就。

CNMD 龙悦 PRO 是一款面向中文用户的便携式 Markdown 阅读与轻编辑工具。以舒适阅读为基础，融合所见即所得、语法编辑、图表与公式处理，解压即用，轻巧而实用。

阅读舒适，编辑简单，图表与公式兼顾。

它不只是文档查看器，也不以重型专业编辑平台为目标，而是把日常阅读、写作和资料整理所需的常用功能集中在一个便携工具里。不必为了查看或修改 Markdown 搭建一套开发环境。“轻编辑”强调上手简单、操作集中，不代表只能查看或修改少量文字。

## 程序特色

- **轻巧便携，解压即用**：无需安装本程序，无需配置 Node.js、Rust 等开发环境；运行所需的 WebView2 条件见下方说明。
- **阅读舒适，布局灵活**：多标签与目录导航方便切换内容；正文自适应窗口，目录宽度可拖动调整，目录与正文可独立缩放，字体、亮色配色及深浅主题可按习惯设置。
- **两种编辑方式，兼顾新手与熟手**：既能直接编辑 Markdown 标记，也能使用所见即所得编辑；不熟悉语法，也能开始写作和整理文档。
- **图表与公式，阅读编辑兼顾**：支持 Mermaid 和数学公式；图表可单独打开，缩放、旋转、拖动查看，多种常见图表提供表单式可视化编辑，复杂语法保留源码编辑方式。
- **复制内容，整理更省心**：识别剪贴板中的 Markdown、富文本及表格，方便整理从 ChatGPT 等网页复制的内容，减少手工补写标记。
- **常用功能齐备，日常操作顺手**：新建、打开、保存、另存、搜索、撤销重做、打印及系统 PDF 输出，配合打开历史和阅读位置记录，覆盖常见阅读与编辑流程。
- **本地优先，免费使用**：无需账号，无广告和应用遥测；自愿赞助不影响全部现有功能。文档中的远程图片仍可能联网。

## 功能

- 多标签、目录导航、搜索、深浅主题、自定义阅读字体和配色。
- 新建、保存、另存为、未保存提醒、阅读位置记忆。
- 所见即所得与带行号的 Markdown 语法编辑、撤销重做。
- 智能粘贴网页表格、原始 Markdown 和制表符表格。
- Mermaid 大图缩放、旋转、拖动；常见图类表单编辑，复杂语法回退源码。
- 数学公式显示与可视化输入、代码高亮、打印及系统 PDF 输出。

## 下载与运行

请在 [下载页面](https://github.com/redknight001/CNMD/releases/latest) 下载完整发布 ZIP，解压后运行 EXE。

支持 Windows 10/11 x64，需要 WebView2 Runtime；无需另装 Node.js、Rust 或 .NET。未商业签名，首次运行可能提示未知发布者，请核对来源和 SHA-256。

## 使用边界

当前版本支持 UTF-8 Markdown，单文件上限 32 MB。“常用功能齐备”不表示兼容全部 Markdown 扩展、复杂排版或所有图表的可视化编辑。本程序不是完整 LaTeX 排版系统，也不是全语法 Mermaid 拖拽画布。网页粘贴、可视化转换和打印结果请核对，重要文件请先备份。
